# Shivani Kumari — Portfolio

Personal portfolio of Shivani Kumari: a static, single-page site built with plain HTML, CSS and JavaScript.

**Live:** https://shivani-portfolio.vercel.app _(update after deploy)_

## Sections

A hero section, followed by 8 checkpoints:

1. Intro
2. Skills
3. Projects
4. Experience
5. Education
6. Lens (photography)
7. Code (GitHub)
8. Contact

## How to update

- All content lives in **`data.js`**. Edit the text there; no HTML changes needed.
- Photos go in **`assets/`**.
- Resume: replace **`assets/Shivani_Kumari_Resume.pdf`** (keep the same file name).
- Photography: add images to `assets/` and list them in the **photos array in `data.js`**.

## Run locally

No build step. Just open `index.html` in a browser, or serve the folder:

```bash
npx serve
```
